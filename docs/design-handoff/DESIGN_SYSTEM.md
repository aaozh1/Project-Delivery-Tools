# DPM (Design Project Manager) — ระบบภายในบริษัทออกแบบสถาปัตยกรรม/ตกแต่งภายใน (ไทย)

## โครงสร้างองค์กร
บริษัท → แผนก → Squad → โครงการ → งวดงาน
- 4 สายงาน: สถาปัตยกรรม (AR) · ตกแต่งภายใน (ID) · บ้านพักอาศัย (House) · กราฟิก (Graphic)
- แต่ละแผนกมีหลาย Squad; หัวหน้า Squad = Senior Designer
- 1 Squad = สมาชิก 3–6 คน ดูแล 2–4 โครงการ
- หัวหน้า Squad จัดสรรได้เฉพาะคนใน Squad ตัวเอง — ห้ามข้าม Squad
- เฉพาะหัวหน้าแผนกเท่านั้นที่ย้ายคนข้าม Squad ได้

## หน่วยวัดงาน
"คน-สัปดาห์" (person-week) · 1.00 = เต็มสัปดาห์ให้โครงการเดียว · ป้อนทีละ 0.25
ไม่มีการลงเวลารายชั่วโมง/รายวันโดยเจตนา

## ระบบภาพ (ใช้เคร่งครัดทุกหน้า)
อารมณ์: สตูดิโอสถาปัตยกรรม — สงบ แม่นยำ มีระเบียบ ไม่ใช่ SaaS สีจัด ไม่ใช่ fintech dashboard

สี
- พื้นหลัง #FAFAF8 · พื้นรอง/แถบข้าง #F2F1ED
- ตัวอักษร #1C1C1A · รอง #6B6B66 · จาง #9A9A94
- สีเน้นเดียว #2B4C7E (น้ำเงินหมึก) ใช้ประหยัดมาก
- สถานะ: เขียวปกติ #2F7A4F · เหลืองเตือน #C79A2E · แดงวิกฤต #B33A3A · น้ำเงินโหลดต่ำ #5B7C99
- เส้นกรอบ #E3E2DD 1px

ตัวอักษร
- IBM Plex Sans Thai (เนื้อหาไทยทั้งหมด)
- ตัวเลข tabular figures เสมอ (font-variant-numeric: tabular-nums)
- จำนวนเงินใช้ ฿ ย่อ M / K เมื่อยาว

รูปทรง/ระยะ
- มุมโค้ง 4px (ปุ่ม/ช่องกรอก) · 6px (การ์ด)
- ระยะห่างฐาน 8px · แถบข้าง 240px · ความกว้างสูงสุด 1440px
- ใช้เส้นแบ่งบางแทนเงา หลีกเลี่ยง drop shadow

ข้อห้าม
✗ gradient ✗ การ์ดเงาหนา ✗ ไอคอนหลากสี ✗ สีเน้น >1 สี ✗ emoji เป็นไอคอนหลัก

หลักการ
- สถานะต้องมีทั้งสี + สัญลักษณ์ (ห้ามพึ่งสีอย่างเดียว)
- ผู้บริหารอ่านตัวเลขสำคัญได้จากระยะ 2 เมตร
- ทุกที่ที่ "ทำไม่ได้" ต้องบอกด้วยว่า "ต้องทำอย่างไร"
- ภาษาไทยทั้งหมด คำต้องไม่ล้นกล่อง
- ต้องดูเหมือนเครื่องมือที่ดีไซเนอร์เคารพ
